## Description

This project is inspired by the gaming platform Friv. Instead of offering a collection of separate games, I will create one game that progresses through diffrent levels  each with its own visual style and increasing difficulty. the player controls a character that runs continuously on top of the city buildings to stay in the game. As time passes,  the environment and obstacles change, making it progressively  harder. If the player hits an obstacle, the game ends.
