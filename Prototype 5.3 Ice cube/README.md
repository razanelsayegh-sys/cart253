# Ice splash

Razan Elsaygh

[View this project online](https://razanelsayegh-sys.github.io/cart253/Prototype%205.3%20Ice%20cube)

## Description

This drawing shows an ice cube falling into water creating splashes. The animation is triggered with a keyPressed event, that the user activate. Th goal is to recreat a small daily moment that we rarely pay attention to, and make it feel noticeable and satisfying.
