# Notification

Razan Elsaygh

[View this project online](URL_FOR_THE_RUNNING_PROJECT)

## Description

This program shows a phone that reacts when a notification appears. The animation is trigged with a time event. The animation is a parody of how phones constantly gives us adernaline with sudden alerts compared to the quiet moment of wait when nothing happens. The users doesn't need any controls, they simply watch the phone switch from calm to active when the notification event occurs.
