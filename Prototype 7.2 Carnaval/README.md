# Carnaval

Razan Elsaygh

[View this project online](https://razanelsayegh-sys.github.io/cart253/Prototype%207.2%20Carnaval/)

## Description

Create a colourful carnival booth filled with ballons. By using the mouse pressed function the user can click and pop the ballons, causing new ballons get to appear on the screen. Inspired by my previous prototype, The Mask, I wanted to explore how using arrays could change the structure of my code while still creating the same effect.
