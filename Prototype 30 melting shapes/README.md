# Melting in the sun

Razan Elsaygh

[View this project online](URL_FOR_THE_RUNNING_PROJECT)

## Description

This  prototype is a simple animated drawing that shows an ice cream slowly melting over time. It begins with a static ice cream scoop on top of the cone, but as the program runs, the ice cream gradually shrinks and melting drops start falling from it. This prototype explores transformation, movement and repetition.
