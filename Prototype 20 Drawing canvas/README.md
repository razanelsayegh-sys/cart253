# The shower 

Razan Elsaygh

[View this project online](URL_FOR_THE_RUNNING_PROJECT)

## Description

This prototype is an interactive shower drawing that reacts to mouse movement. Moving the mouse with to the left creates falling water drops, while moving it to the right creates floating soap bubbles.
